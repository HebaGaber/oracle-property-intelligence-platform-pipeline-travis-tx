## Notes for the reader

- **Kit auto-advance is overridden.** The readiness report says `auto_advance_required: true` and names "start the next dependency-ready stage" as the next action. In this project nothing starts automatically: seed is story A-04, behind its own gates G4 to G7 (`agent-design.md`).
- **The durable run's state is not the catalog's state.** Run `travis-2` wrote the catalog on 2026-10-19 and 2026-10-20 (snapshot 05:43:09Z). The changes after that were made by offline commands (table above), each recorded in the catalog's `amendments` list. A fresh `discover` from the operator's network would not reproduce the GIS count, the reconciliation or the exception.
- **The TCAD export was requested more than once, not once.** The broken download in run `travis` stopped at 158,646,272 bytes (2026-10-19T20:41:35Z). One in run `travis-2` stopped at 1,287,539,237 bytes (21:01:07Z, `docs/evidence/blocked/tcad_certified-20261019T210107Z.md`). The download that completed the file (receipt captured 21:33:41Z) needed one range resume (`resumes: 1`). The catalog's `anti_bot` records `requests: 3`. AC-3 says "downloaded once"; the file was completed once, and discovery now skips the download when a receipt with a matching size and SHA-256 exists.
- **Deviations from the source rules** are listed in `docs/decisions/DEC-A-01-source-access.md` (D-1 VPN during the 2026-10-19 runs, D-3 three retries of blocked sources on 2026-10-20). D-2 (the US-runner count) is an approved rule amendment, not a deviation.
