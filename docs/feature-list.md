## 1. Vision alignment

**Source vision:** `VIS-A` (approved 2026-10-17)

**Problem:** Travis County roofing-lead evidence is scattered across many public sources. Nothing joins it into one current, source-backed record per property that outlives its builders at zero standing cost.

**Actors:**
- CRM developer
- AI agent
- Roofing sales rep (through the CRM)
- Oracle operator
- Independent retriever
- Evaluator

**Expected outcome:** all available Travis County data is loaded, reconciled and refreshed incrementally. It is published as immutable public CIDs and answers roofing-lead questions through a UI, an agent and an MCP-ready interface.
