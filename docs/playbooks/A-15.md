## Draft acceptance criteria (put these in the story file, then edit)

As a **agent developer**, I want **an MCP endpoint over the same views**, so that **agents and the CRM can query without changing the data model**.

1. Given the hosted MCP URL and token, when MCP Inspector connects, then it lists listScopes, getSchema, query and the roofing tools.
2. Given query(sql), when it is a single read-only SELECT or WITH, then it returns at most 1000 rows.
3. Given a write or multi-statement SQL, when sent, then it is rejected with a clear error.
4. Given donphan or Claude Desktop, when connected, then it answers a roofing question through the MCP.
