## Draft acceptance criteria (put these in the story file, then edit)

As a **roofing sales rep**, I want **BBB ratings on resolved contractors where they are publicly available**, so that **reps can judge contractor quality**.

1. Given resolved companies, when BBB enrichment runs, then ratings link to companies as enrichment only, never as identity.
2. Given the run finishes, when coverage is reported, then the BBB coverage percent is shown on the Coverage page.
3. Given BBB returns 403, when the probe runs, then harvesting stops, evidence is kept and the limitation is recorded.
4. Given a contractor without a BBB profile, when shown, then the UI says BBB rating not available with the reason.
