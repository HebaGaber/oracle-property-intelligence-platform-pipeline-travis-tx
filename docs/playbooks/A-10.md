## Draft acceptance criteria (put these in the story file, then edit)

As a **roofing sales rep**, I want **one record per real entity and a roof age with its basis**, so that **aged-roof leads are correct and explainable**.

1. Given all loaded datasets, when reconciliation runs, then duplicate statistics are shown and each merged entity keeps all its sources.
2. Given a property, when roof age is derived, then it has a basis (reroof permit or year built) and a confidence (high, medium, low).
3. Given the estimator, when it is re-run, then rowsWritten is 0 (idempotent).
4. Given a threshold N, when queried, then properties with roof age over N are returned.
5. Given a property with no basis, when shown, then the UI says roof age unknown with the reason.
