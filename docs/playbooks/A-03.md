## Draft acceptance criteria (put these in the story file, then edit)

As a **data operator**, I want **a hosted Explorer that lists real permits read from an IPFS CID**, so that **the hosted-runtime gate is safe from day 3 and every later story grows a working app**.

1. Given a private browser window, when explorer.{domain} (or the Amplify URL) opens, then the Runs page lists the pilot run with its manifest CID.
2. Given the pilot manifest, when the Permits page loads, then it lists one month of real Austin reroof permits read through DuckDB-WASM from the gateway CID.
3. Given runs/{runId}/manifest.json, when verify-manifest runs, then every artifact has cid, name, size, codec and sha256 and is verified.
4. Given the gateway returns 429, when the page loads, then a rate-limited state with retry shows instead of a blank table.
5. Given a page load, when it completes, then a log line is in CloudWatch and a trace is in X-Ray.
