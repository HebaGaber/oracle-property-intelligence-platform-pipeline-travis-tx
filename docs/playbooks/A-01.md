## Draft acceptance criteria (put these in the story file, then edit)

As a **data operator**, I want **know every Travis County source, its size, its limits and its refresh mechanism before building**, so that **ingestion is planned against real numbers and every gap is known up front**.

1. Given the TCAD exports and the city and county portals, when discovery runs, then pipeline/docs/travis-sources.yaml lists every source with URL, format, record volume, refresh mechanism, rate limits and terms.
2. Given every permit jurisdiction in Travis County, when discovery runs, then each is classified supported, records-request or no-public-history, with evidence.
3. Given the certified roll and the GIS parcel layer, when both are counted, then the two counts and their difference are recorded.
4. Given the readiness validator, when it runs, then it exits 0 or every blocker is listed with an owner.
5. Given a source that geo-blocks or rate-limits, when it is probed, then the measured throughput and a bulk-vs-runtime decision are recorded instead of a failure.

```text
Use the soofi-xyz-team-kit:oracle subagent. Read skills/use-oracle/SKILL.md first.
Run onboard-county intake for Travis County, TX (FIPS 48453), local Restate + Postgres stack,
scope = full county, US egress = {yes/no}. Then run county-discovery and
county-readiness-preflight.

Known facts (verified 2026-10-15):
- TCAD publishes Certified Appraisal Export, Certified Special Export (JSON), Supplemental
  exports and Export Layouts at traviscad.org/publicinformation. Raw files are in
  pipeline/data/raw/tcad/.
- City of Austin permits: Socrata 3syk-w9eu (2.38M rows; has tcad_id, latitude, longitude,
  contractor_company_name, status_current, issue_date, expiresdate, completed_date;
  :updated_at filter works). No Socrata adapter exists in the runtime yet.
- Travis County GIS parcels: ArcGIS MapServer TCAD_PARCELS (max 2000 records/query);
  runtime has an arcgis-feature-service adapter.
- Texas Comptroller Active Franchise Tax Permit Holders: data.texas.gov 9cir-efmm.
- Texas has no state roofing license (confirm); contractor identity must come from official
  records or stay unresolved.

Produce pipeline/docs/travis-sources.yaml in the same shape as runtime/docs/duval-sources.yaml:
parcel denominator (certified roll count), GIS feature count and difference, every permit
jurisdiction classified (supported / records-request / no-public-history) with evidence,
throughput measurements, and the >48h bulk-vs-runtime decision per source. Then run the
readiness validator and show its exit code. Write docs/sources.md as a human summary.
```

Commands from the walkthrough for this story (run them yourself):

```bash
B=https://data.austintexas.gov/resource/3syk-w9eu.json
curl -s "$B?\$select=count(*)"                                              # ≈ 2.38M rows
curl -s "$B?\$select=status_current,count(*)&\$group=status_current&\$order=count(*)%20DESC"
curl -s "$B?\$select=jurisdiction,count(*)&\$group=jurisdiction&\$limit=50"
# reroof candidates by type/class/status
curl -s "$B?\$select=permittype,work_class,status_current,count(*)&\$where=upper(description)%20like%20'%25REROOF%25'%20OR%20upper(description)%20like%20'%25RE-ROOF%25'&\$group=permittype,work_class,status_current&\$order=count(*)%20DESC&\$limit=30"
# incremental window
curl -s "$B?\$select=count(*)&\$where=:updated_at>'2026-10-01T00:00:00'"
```
