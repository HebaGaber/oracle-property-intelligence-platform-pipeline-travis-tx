## Draft acceptance criteria (put these in the story file, then edit)

As a **data operator**, I want **accurate coordinates on every property**, so that **radius searches return the right properties anywhere in the county**.

1. Given the roll, when coordinates are attached, then at least 99% of properties have a coordinate.
2. Given a property, when it has a coordinate, then its coordinate source (GIS centroid or permit lat/lon) is recorded.
3. Given properties without a coordinate, when the gap is reported, then each is classified (no geometry, confidential, new split).
4. Given a 5 mi radius anywhere in the county, when it is queried, then results come back.
5. Given a property without geometry, when it is shown, then the UI says location not available with the reason.
