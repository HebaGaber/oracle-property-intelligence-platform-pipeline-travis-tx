## Draft acceptance criteria (put these in the story file, then edit)

As a **third party**, I want **every artifact published by CIDv1 with a manifest I can verify from public gateways**, so that **the dataset outlives the candidate environment**.

1. Given the run, when publishing finishes, then the manifest lists every artifact with cid (v1), name, size, codec and sha256.
2. Given directory artifacts, when published, then a CAR exists for each and is attached to a GitHub Release.
3. Given IPNS is used, when the manifest is written, then it records the IPNS name and the resolved CID.
4. Given verify-manifest, when it fetches from ipfs.io and dweb.link, then sizes and digests match.
5. Given a gateway 429 or a digest mismatch, when Verify runs in the UI, then the retrying or mismatch state shows.
