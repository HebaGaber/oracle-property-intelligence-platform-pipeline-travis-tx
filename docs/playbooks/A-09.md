## Draft acceptance criteria (put these in the story file, then edit)

As a **data operator**, I want **business and places records for Travis County**, so that **coverage includes business data as the README asks**.

1. Given a pinned Overture release, when ingestion runs for the county boundary, then places load with the licence recorded.
2. Given the run finishes, when counts are reported, then counts by category show on the Coverage page.
3. Given a places record with a licence that blocks publication, when publishing, then it stays out of the public group.
